# Legacy SQL (archive)

These are the one-off SQL scripts that were run by hand in the Supabase SQL
editor before the project moved to versioned migrations. They are kept for
history only.

- Do not run them against the live database again.
- New schema changes go in `supabase/migrations/` (timestamped files).
- `docs/PHASE6_DATABASE_WORKFLOW_AUDIT.md` refers to these files by their
  original `supabase/<name>.sql` paths.
